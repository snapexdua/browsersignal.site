Choose hosting from what your site actually does

Compare static publishing, trusted server-side work, domain renewal and first-renewal cost using one small-site example.

Lilik HartantiPublished 27 November 2026

A school club is paying for a website, a registered name and two mailboxes. Its guide library is HTML with a client-side search box. A new membership area would hold private documents. Those two workloads lead to different hosting decisions even when the public pages look identical.

List what happens after someone opens a page

For public articles, the host can return prebuilt HTML and CSS. A filter that searches a small public index can run in the visitor’s browser. A domain, HTTPS, real 404 responses and predictable nested paths still matter. List these as requirements when comparing static hosts.

For private member files, pay attention to who authorizes each request. Hiding a public download link with JavaScript leaves its address accessible. A service that checks identity and permission before returning the file needs a trusted server, an edge function or a managed service with equivalent access controls. Ask where private files are stored, how access is revoked, and how to export them when changing hosts.

Compare a first term and a renewal term

Illustrative two-year quotes in USD, excluding tax and overages
Annual line itemPlan A year 1 / year 2Plan B year 1 / year 2
Hosting$36 / $84$60 / $60
Domain$0 / $18$16 / $16
Two mailboxes together$24 / $24$0 / $0
Total$60 / $126$76 / $76

Plan A saves $16 in year one. Over both years it totals $186, compared with $152 for B. The difference depends on keeping both mailboxes and renewing for a second year. With an existing mail service, take its cost out of both quotes before comparing them. These figures are an arithmetic example. Use your providers’ quoted renewal dates, billing periods and currency for an actual decision.

Ask what a limit does to a reader

Distinguish a hard transfer cap from paid overage and from a temporary pause. For a rough transfer estimate, 1,000 uncached transfers of a 2 MB file use about 2 GB in decimal units before protocol overhead. A provider may meter delivery differently, including CDN and function activity. Ask what the quota measures, when it resets and whether a usage alert is available. A marketing label such as “unlimited websites” gives little information about a single popular file.

Run a small acceptance test before moving the name

Publish one public article, a nested URL, a small asset and a missing path on the preview. Check whether rollback restores a known page. For the private workload use a disposable, non-sensitive file and the service’s ordinary signed-out and authorized-user flows. Confirm the endpoint enforces the intended access. Record how you can export the site, regain access to the domain independently, and move mailboxes if you later leave.
