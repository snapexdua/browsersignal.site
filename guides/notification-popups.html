Accounts & privacy

Stop unwanted website notifications without breaking useful alerts

Identify who sends a notification and remove the permission at the correct level.

By BrowserSignal EditorialPublished: 9 Nov 2026How-to guide

A surprising number of “virus detected” banners are not operating-system alarms; they can be website push notifications granted accidentally. Others are legitimate browser or application alerts. The safest first step is identifying the sender rather than clicking a message that may lead to a deceptive website. You can often fix the problem through site permissions without uninstalling the browser or paying for a cleaning utility.

First principle

Revoke permission at the sender, not globally. Do not enter passwords on unverified pages or bypass browser security warnings.

01 / THE CHECK

Do not interact with a suspicious notification

If an alert uses urgent threats, demands payment, or asks you to call an unfamiliar number, do not click its buttons. Close it using the operating system’s normal control. Record the displayed website domain if visible. A legitimate safety alert should be confirmed through the official security application, not by following a telephone number in a pop-up.

02 / THE CHECK

Identify the notification source

Look at the notification’s app name and sender. If it comes from a browser, inspect the browser’s notification-permission list. If it comes from an installed application, use that app or operating-system settings instead. The objective is to remove the permission of the unwanted sender, not silence every notification and miss meaningful reminders.

03 / THE CHECK

Revoke the site permission

In your browser’s site settings, find Notifications and review the allowed websites. Remove or block domains you no longer trust. Browser menu labels vary by version, so consult official help if a setting has moved. Do not grant notification permission to a website simply because a prompt claims it is necessary to read an article or complete a download.

04 / THE CHECK

Check extensions only when the pattern continues

If alerts persist after site permission cleanup, investigate browser extensions and installed applications. A browser notification permission does not explain every system pop-up, and an extension may generate its own UI. On a managed work device, ask IT before removing software. If a suspicious application was installed, use the device’s trusted security tools and official vendor guidance.

05 / THE CHECK

Reduce future prompts thoughtfully

Many browsers allow you to quiet notification prompts globally or require sites to ask first. This can reduce accidental approvals. Keep notification permissions for services you actively use, and periodically review unfamiliar domains. Never share screenshots that expose private messages, account names, or workplace details when asking for help.

FIELD EXAMPLE

How this looks in practice

A user receives repeated “security infection” notices that display a strange web domain even when the site is closed. The browser’s allowed-notifications list contains that domain. Revoking its permission stops the notices. The user then verifies device security through built-in tools rather than paying the fake notification’s support number.

TAKE-AWAY

Your short checklist

  1. Do not click alarming notification links.
  2. Identify browser versus system sender.
  3. Review allowed site domains.
  4. Revoke suspicious permissions.
  5. Check extensions if notices continue.
  6. Keep only useful alerts enabled.
