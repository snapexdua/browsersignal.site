A first-party pass has a narrow meaning

This page writes, reads and removes a new temporary value in local storage, session storage and a first-party cookie. A fresh key keeps the test separate from your saved Fix Log. Session storage is tied to the current tab’s session.

Decide what to check next

If one store fails here, check this origin’s site settings. If all three pass but a login still loops elsewhere, examine that service’s identity-provider flow and site-specific permissions. An embedded third-party cookie follows different rules.
