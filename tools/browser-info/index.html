What the browser is willing to report

The language value is the browser interface preference. The platform hint may be generalized. A work browser may report settings set by its administrator. For a support ticket about an update, record the actual version from the browser’s About screen as well.

Decide what to check next

Compare two profiles on the same device. A different language can explain localization changes. A different secure-context result calls for checking the exact address and embedding context before assuming a missing feature.
