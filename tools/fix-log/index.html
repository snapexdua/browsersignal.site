TOOL 02 / FIX NOTES

Keep a Fix Log.

Write down what you tested so you do not erase useful evidence or repeat the same fixes. The log stays in this browser until you delete it.

01

The incident

Use a short description; do not record passwords, tokens or private URLs.

02

Which tests did you try?

Check only what you actually did, not the steps you plan to try.

THE METHOD

A clean report helps the next person.

A useful report is specific and reproducible. “The upload button fails in Safari after sign-in, but works in Firefox” is more helpful than “the internet is broken.”

You can export a text file to attach to an official support request. Review it first for any sensitive details you may have typed.

Storage explained

Save stores a draft using localStorage in this browser. Removing site data may erase it. The export is a downloadable plain-text file created in your browser; nothing is uploaded to us.
