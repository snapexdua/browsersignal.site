DNS Cutover Worksheet

Estimate an overlap window for old DNS answers when you lower the TTL before changing a web record.

Work the example by hand

A 3,600-second record is lowered to 300 seconds, then switched 20 minutes later. The longer-lived entry has at most 3,600 − (20 × 60) = 2,400 seconds remaining. The newer entry can last 300 seconds. Plan around the larger figure of 40 minutes after the switch for this model.

Change the lead time to 60 minutes. The older entry’s modeled window falls to zero, and the shorter entry can last five minutes. A resolver can discard an entry earlier.

What the estimate covers

One existing positive DNS record, the same name and type, and authoritative servers publishing the intended TTL and answer. The formula assumes ordinary TTL-respecting caches.

Negative DNS responses, delegation changes, serving stale data and HTTP or application caching have their own behavior. This worksheet performs no DNS lookups and predicts no global completion time.
