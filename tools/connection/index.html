Read the three requests as a set

The test fetches the same small file three times with the browser cache bypassed and checks its body. A first request can include connection setup and later ones may reuse that connection. Three results describe this path at the time you ran it.

Decide what to check next

HTTP 200 with an unexpected body can indicate that routing returned an HTML page. A timeout is inconclusive. Retry once on a second network if available, keep the observed status, and compare with a different public site. The three times cannot isolate DNS latency or estimate download bandwidth.
