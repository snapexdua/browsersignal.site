    HOW TO USE THIS

    One variable at a time.

    Choose the closest symptom even if you are uncertain about the cause. The first recommendation is usually to compare another browser, device, network or clean profile.

    A private or Guest window is a comparison, not absolute proof of an extension or cookie fault. If you see a security warning, avoid proceeding with sensitive information.

    What we never do

    We never ask you to enter a password, install third-party repair utilities, or bypass HTTPS warnings. The selections are processed locally.
