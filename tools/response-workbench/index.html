Response Workbench

Fetch three fixed examples from this site and compare the returned status, media type and body as if a page had requested a stylesheet.

Inspect three responses

This check sends three ordinary requests to BrowserSignal. One fetches CSS, one deliberately requests an HTML document as a stand-in for an incorrect fallback, and one asks for a file that was never published. The displayed values come from this run.

Ready to request the three examples.

What should a stylesheet request receive?

For the working specimen, look for HTTP 200, a media type of text/css and a body containing CSS. In the second specimen the host serves a real HTML document. A 200 there still leaves a stylesheet consumer with the wrong kind of content. The third path should return 404 on a host preserving missing-file responses.

A host with a broad fallback might return HTML with 200 even for the missing path. The tool shows the received values in that case. If a request fails before a readable response, its error occupies the result for that sample.

Use it on your own page

Open your browser’s Network panel, reload the affected page and select the stylesheet request. Compare its address, status, Content-Type and first line with these examples. A different site may use different routes and caching rules.
